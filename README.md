# AI Research Agent App

A premium, Neo-Lab styled interface for your autonomous n8n Research Agent.

## Setup

1.  **Install Dependencies** (if not already done):
    ```bash
    npm install
    ```

2.  **Start Development Server**:
    ```bash
    npm run dev
    ```

3.  **Open App**:
    Navigate to [http://localhost:3000](http://localhost:3000).

## Features

*   **Neo-Lab Aesthetic**: Dark mode, glows, and futuristic typography.
*   **Terminal Input**: "Command Line" accessible search.
*   **Live Logging**: Visual feedback of the agent's "thinking" process.
*   **Markdown Rendering**: Clean, professional report display.
